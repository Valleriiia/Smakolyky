# 🍲 Смаколики

Мобільний Android-додаток для пошуку, перегляду та приготування кулінарних рецептів.

> Курсова робота з дисципліни «Розробка програмного забезпечення мобільних пристроїв»
> НТУУ «КПІ ім. Ігоря Сікорського», кафедра інженерії програмного забезпечення в енергетиці

## Про проєкт

**Смаколики** — це застосунок, який дозволяє користувачам знаходити рецепти страв, переглядати покрокові інструкції приготування з відео та таймером, зберігати улюблені рецепти та формувати список покупок. Каталог страв отримується з відкритого API [TheMealDB](https://www.themealdb.com/api.php), а власні рецепти, улюблене, оцінки та список покупок користувача зберігаються на власному сервері застосунку.

## Основні можливості

- Пошук рецептів за назвою, категорією та кухнею світу
- Випадковий рецепт («Здивуй мене»)
- Детальна сторінка рецепта: інгредієнти (з перерахунком на кількість порцій), покрокова інструкція, відео
- Режим покрокового приготування із вбудованим таймером і фоновими сповіщеннями
- Улюблені рецепти
- Список покупок, автоматично сформований з інгредієнтів обраних рецептів
- Оцінки та коментарі до рецептів
- Створення й редагування власних рецептів
- Реєстрація та авторизація користувачів, доступ у режимі гостя до публічного каталогу

## 🛠️ Технологічний стек

**Клієнт (Android)**
- Kotlin, Jetpack Compose
- Архітектура MVVM (ViewModel + StateFlow)
- Retrofit / OkHttp — мережеві запити
- Room — локальне кешування та офлайн-доступ
- DataStore — зберігання токена авторизації
- Hilt — впровадження залежностей
- WorkManager — фонова синхронізація
- Foreground Service — робота таймера приготування

**Сервер**
- Kotlin, Ktor
- Exposed (ORM)
- PostgreSQL
- JWT-автентифікація

**Зовнішні сервіси**
- [TheMealDB API](https://www.themealdb.com/api.php) — каталог рецептів
- YouTube — відеоінструкції приготування

## Архітектура

Клієнтська частина побудована за патерном **MVVM**: екрани на Jetpack Compose спостерігають за станом у ViewModel, ViewModel звертається до репозиторіїв, а репозиторії узгоджують дані між віддаленим API (TheMealDB, власний бекенд) і локальним кешем Room. Серверна частина — окремий Ktor-застосунок з REST API, що обробляє автентифікацію, улюблені рецепти, оцінки та список покупок, зберігаючи дані в PostgreSQL.
